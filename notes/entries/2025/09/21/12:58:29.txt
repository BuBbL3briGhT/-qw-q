To add a key-value pair to a dictionary (associative array) in Bash, you first need to declare the variable as an associative array and then assign the key-value pair.
1. Declare the Associative Array:
Use declare -A to declare the variable as an associative array.
declare -A my_dictionary

2. Add Key-Value Pairs:
Assign values to keys using square bracket notation.
my_dictionary[key1]="value1"
my_dictionary["key with spaces"]="another value"

You can also use variables for keys and values:
new_key="dynamic_key"
new_value="dynamic_value"
my_dictionary[$new_key]=$new_value

Example:
#!/bin/bash

# Declare an associative array
declare -A user_info

# Add key-value pairs
user_info[name]="Alice"
user_info[age]=30
user_info[city]="New York"

# Add a key-value pair using variables
department="job_title"
title="Software Engineer"
user_info[$department]=$title

# Print the values to verify
echo "Name: ${user_info[name]}"
echo "Age: ${user_info[age]}"
echo "City: ${user_info[city]}"
echo "Job Title: ${user_info[job_title]}"
