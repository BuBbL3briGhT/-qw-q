To add values to an associative array declared outside a while loop from within the loop in Bash, it is crucial to understand how subshells affect variable scope. When you pipe output to a while loop (e.g., command | while read ...), the while loop executes in a subshell, meaning any modifications to variables within that loop are not reflected in the parent shell where the array was declared.
Here are two common methods to achieve this:
1. Using Process Substitution (Recommended):
Process substitution (&lt;()) allows you to run the while loop in the current shell's context, avoiding the subshell issue.
declare -A my_array

# Simulate some input
input_data="key1 value1
key2 value2
key3 value3"

while read -r key value; do
  my_array["$key"]="$value"
done < <(echo "$input_data")

# Verify the array contents
for key in "${!my_array[@]}"; do
  echo "Key: $key, Value: ${my_array[$key]}"
done

Explanation:

• declare -A my_array: Declares an associative array named my_array.
• while read -r key value; do ... done &lt; &lt;(echo "$input_data"): This is the key part.
	• &lt; &lt;(...): This is process substitution. The command inside () (here, echo "$input_data") is executed, and its output is treated as a temporary file, which is then redirected as standard input to the while loop.
	• Because the input is redirected from a "file" (the process substitution), the while loop runs in the current shell, allowing modifications to my_array to persist.

2. Using a Temporary File:
This method involves writing the data to a temporary file and then reading from it in the while loop. This is less efficient than process substitution but can be useful in specific scenarios.
declare -A my_array
temp_file="/tmp/my_data.txt"

# Simulate some input and write to a temporary file
echo "keyA valueA" > "$temp_file"
echo "keyB valueB" >> "$temp_file"
echo "keyC valueC" >> "$temp_file"

while read -r key value; do
  my_array["$key"]="$value"
done < "$temp_file"

# Verify the array contents
for key in "${!my_array[@]}"; do
  echo "Key: $key, Value: ${my_array[$key]}"
done

# Clean up the temporary file
rm "$temp_file"

Explanation:

• The input data is explicitly written to a temporary file.
• The while loop then reads from this file, which also ensures it runs in the current shell and can modify my_array.

Choosing the right method:

• For most cases, process substitution (&lt;()) is the preferred and more elegant solution as it avoids the overhead of creating and managing temporary files.
• The temporary file method might be considered if the data source is already a file or if there are specific reasons to avoid process substitution.
