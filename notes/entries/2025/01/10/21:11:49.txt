In Bash, you can set default values for environment variables using the following methods:
1. Using the Colon-Hyphen Operator (:-)
This is the most common way to set a default value.
${VARIABLE:-default_value}

If VARIABLE is unset or empty, it will expand to default_value. Otherwise, it will expand to the value of VARIABLE.
Example:
echo "${USER:-guest}"

This will print the current user's username if it's set, otherwise it will print "guest".
2. Using the Colon-Equals Operator (:=)
This operator not only provides a default value but also assigns it to the variable if it's unset or empty.
${VARIABLE:=default_value}

Example:
echo "${USER:=guest}"

This will print the current user's username if it's set, otherwise it will print "guest" and also set the USER variable to "guest".
3. Setting Defaults in Scripts
You can set default values for variables within your Bash scripts:
#!/bin/bash

: "${GREETING:=Hello}"
: "${NAME:=World}"

echo "$GREETING, $NAME!"

In this script, if GREETING or NAME are not set when the script runs, they will default to "Hello" and "World" respectively.
4. Setting System-wide Defaults
To set system-wide defaults, you can edit the /etc/profile file or the /etc/environment file (depending on your distribution). Be cautious when modifying these files, as incorrect changes can impact your system.
