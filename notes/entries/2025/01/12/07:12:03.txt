Node.js loaders provide a way to customize the module loading process, allowing you to handle different file types, transpile code on the fly, and more. Here's a breakdown of how they work:
What are Loaders?
Loaders are functions that hook into Node.js's module resolution and loading mechanism. They allow you to:

• Transform code: Convert code from one format to another (e.g., TypeScript to JavaScript).
• Resolve modules: Customize how Node.js finds modules.
• Load modules: Control how modules are loaded and executed.

How to Use Loaders

• Enable Loaders: Since Node.js v12, loaders are experimental and require the --experimental-loader flag.
• Register a Loader: You can register a loader using the --loader flag:

   node --experimental-loader ./my-loader.mjs my-app.js

Common Use Cases

• TypeScript: ts-node is a popular loader that enables you to run TypeScript files directly without prior compilation.
• ESM in CommonJS: Loaders can help bridge the gap between ES Modules and CommonJS, allowing you to use them together.
• Custom File Formats: You can create loaders to handle custom file formats, such as .vue or .graphql.

Example: TypeScript Loader
// my-loader.mjs
import { createRequire } from 'module';
import { resolve } from 'path';
import { fileURLToPath } from 'url';
import ts from 'typescript';

const require = createRequire(import.meta.url);
const tsConfigPath = resolve(fileURLToPath(import.meta.url), '../tsconfig.json');
const tsConfig = require(tsConfigPath);

export function resolve(specifier, context, defaultResolve) {
  if (specifier.endsWith('.ts')) {
    return {
      url: specifier,
      format: 'module',
    };
  }
  return defaultResolve(specifier, context, defaultResolve);
}

export function load(url, context, defaultLoad) {
  if (url.endsWith('.ts')) {
    const code = ts.transpileModule(fs.readFileSync(url, 'utf-8'), tsConfig.compilerOptions);
    return {
      format: 'module',
      source: code.outputText,
    };
  }
  return defaultLoad(url, context, defaultLoad);
}

Future of Loaders
Loaders are still under development and may change in future versions of Node.js. However, they represent a powerful way to extend Node.js's capabilities.
