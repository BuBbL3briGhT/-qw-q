git ls-tree --full-tree --name-only -r HEAD

Explanation of the command:

• git ls-tree: This command lists the contents of a tree object in Git.
• --full-tree: This option makes the command run as if you were in the repository's root directory, ensuring all files are included regardless of your current working directory.
• --name-only: This option displays only the file names, without additional information like file modes or object SHAs.
• -r: This option recursively lists the contents of subdirectories.
• HEAD: This specifies that you want to list the files as they exist in the commit currently pointed to by HEAD, which represents the tip of your current branch.
