To save a list of files to a variable in Bash, the most robust and recommended method is to use a Bash array. This approach handles filenames with spaces or special characters correctly.
1. Using mapfile or readarray (Recommended for Bash 4+):
This method is highly recommended as it handles filenames with spaces and other special characters correctly by default.
mapfile -t my_files < <(find . -maxdepth 1 -type f -print0 | xargs -0 basename)

• find . -maxdepth 1 -type f -print0: Finds regular files in the current directory (not subdirectories) and prints their names separated by null characters.
• xargs -0 basename: Reads the null-separated filenames and extracts just the base filename (without the path).
• mapfile -t my_files: Reads the output line by line (due to -t removing trailing newlines) and stores each line as an element in the my_files array.

2. Using Command Substitution with Globbing (for simple cases):
If filenames do not contain spaces or special characters, you can use simple command substitution with shell globbing.
my_files=(*)

• my_files=(*): Creates an array my_files and populates it with all files and directories in the current directory.
• You can refine the glob, e.g., my_files=(*.txt) for text files, or my_files=(data/*) for files within a data subdirectory.

3. Using Command Substitution with find (for more complex searches):
This method can be problematic if filenames contain spaces or newlines, as it relies on word splitting.
my_files=$(find . -type f -name "*.log")

• my_files=$(find . -type f -name "*.log"): Stores the output of the find command (which lists .log files) into the my_files variable as a single string. This variable will contain filenames separated by newlines.
• To iterate over these files, you would need to adjust your loop, for example, using IFS=$'\n' and a for loop.

Accessing the Array Elements:
Once the list of files is stored in an array, you can access individual elements or iterate through them:

• All elements: ${my_files[@]}
• Number of elements: ${#my_files[@]}
• First element: ${my_files[0]}
• Looping:

    for file in "${my_files[@]}"; do
            echo "Processing: $file"
                done
