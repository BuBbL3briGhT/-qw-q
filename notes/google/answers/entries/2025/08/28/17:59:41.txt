While the for loop in Bash is typically used to iterate over items separated by whitespace, it can be adapted to iterate over lines by manipulating the Internal Field Separator (IFS) or by using command substitution.
1. Using IFS and read within a while loop (Recommended for files/streams):
This is the most robust method for handling lines, especially those containing spaces or special characters.
while IFS= read -r line; do
  echo "Processing line: $line"
  done < input_file.txt

  • IFS=: This temporarily clears the Internal Field Separator, ensuring that read processes the entire line as a single field, preventing splitting on spaces or tabs within the line.
  • read -r line: Reads a single line into the line variable. The -r option prevents backslash escapes from being interpreted.
  • &lt; input_file.txt: Redirects the content of input_file.txt as input to the while loop.

  2. Using for loop with command substitution and IFS modification (for variables):
  This method can be used for iterating over lines stored in a variable, but requires careful handling of IFS.
  my_variable="Line 1
  Line 2 with spaces
  Line 3"

  IFS=$'\n' # Set IFS to newline character
  for line in $my_variable; do
    echo "Processing line: $line"
    done
    IFS=$' \t\n' # Reset IFS to default (space, tab, newline)

    • IFS=$'\n': Sets IFS to only the newline character, so the for loop iterates line by line.
    • for line in $my_variable: The for loop iterates over the contents of my_variable, which are now split by newlines.
    • IFS=$' \t\n': It is crucial to reset IFS to its default value after the loop to avoid unexpected behavior in subsequent commands.

    Important Considerations:

    • Empty Lines: The while IFS= read -r line method handles empty lines correctly. The for loop with IFS=$'\n' might skip truly empty lines if they are not explicitly represented as empty strings in the variable.
    • Trailing Newlines: Be aware of how trailing newlines in your input affect the last iteration, especially when using read.
    • Performance: For very large files, the while read loop is generally more efficient as it processes line by line, rather than loading the entire content into memory first.
